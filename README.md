# SwingSprite

## Usage

With gradle:

```kotlin
repositories {
    mavenCentral()
    maven { url = uri("https://jitpack.io") }
}

dependencies {
    // from the main branch
    implementation("com.github.gabrielemercolino:SwingSprite:main-SNAPSHOT")
    // from a specific tag
    implementation("com.github.gabrielemercolino:SwingSprite:v0.5.0")
}
```
